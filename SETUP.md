# Cyber Command Centre setup

## Files

- `README.md` — compact cybersecurity profile.
- `profile.yml` — single source of truth for links and profile facts.
- `scripts/update_stats.py` — refreshes public TryHackMe/LetsDefend stats.
- `.github/workflows/profile-update.yml` — daily updater + contribution snake.
- `data/platform_stats.json` — last successfully fetched values.
- `assets/cyber-command-center.gif` — animated cyber header.

## One-time setup

1. Keep this repository named exactly `prasiddhapal`.
2. Copy the package contents into that profile repository.
3. Verify `profile.yml`.
4. Make sure the LetsDefend URL is your exact public profile URL.
5. Commit and push.
6. In GitHub, open **Settings → Actions → General → Workflow permissions** and select **Read and write permissions**.
7. Run **Actions → Cyber Profile Command Centre → Run workflow** once.

After that, the workflow runs daily. You do not manually edit streak numbers.

## Important limitation

GitHub profile READMEs support Markdown, HTML, images and GIFs, but they do not execute arbitrary JavaScript. The animation is therefore an embedded GIF, while live values are generated by GitHub Actions.

TryHackMe and LetsDefend can change their public page structure or restrict automated requests. The updater keeps the last successful value instead of inventing a number when a fetch fails.
